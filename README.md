## Назначение

Мод добавляет руду на поверхности внешних островов Энда, осколок, слиток,
меч, топор и кирку Endsteel. Достижения не входят в минимальную версию.

## Целевая конфигурация

- Minecraft Java Edition 1.21.1.
- JDK 21; в среде подготовки использован Eclipse Temurin 21.0.13.
- Fabric Loader 0.16.10 и Fabric API 0.116.17+1.21.1.
- Yarn 1.21.1+build.3; Fabric Loom 1.8.13; Gradle Wrapper 8.10.2.

Эти значения закреплены для проекта; поддержка других версий не заявляется.

## Структура проекта

- `src/main/java/ru/college/i923b/endsteel` — точка входа, регистрации, материал инструментов, обработчик добычи.
- `src/main/resources/fabric.mod.json` — описание и точка входа.
- `src/main/resources/assets/endsteel` — текстуры, модели и локализации.
- `src/main/resources/data/endsteel` — рецепты, пустая таблица добычи руды и генерация.
- `artwork` — исходные векторные рисунки, из которых получены текстуры PNG 16×16.
- `gradle/wrapper`, `gradlew`, `gradlew.bat` — закреплённая система сборки.

## Сборка и запуск

В IntelliJ IDEA открыть проект как Gradle, выбрать JDK 21 в Project SDK и Gradle JVM,
затем выполнить Reload All Gradle Projects. Запускать `classes`, `runClient`, `build`
через окно Gradle. Для финальной сборки на Windows:

```powershell
.\gradlew.bat clean build
```

Linux/macOS: `./gradlew clean build` (при необходимости дать файлу право исполнения).
Ожидаемый основной файл — `build/libs/endsteel-1.0.0.jar`.
`endsteel-1.0.0-sources.jar` в игру не устанавливают.

## Установка после успешной сборки

1. Подготовить отдельный профиль Minecraft 1.21.1 с Fabric Loader 0.16.10.
2. Добавить совместимый Fabric API 0.116.17+1.21.1 в `mods`.
3. Удалить прежнюю копию Endsteel, поместить основной JAR в `mods`.
4. Запустить профиль и проверить предметы, ресурсы и рецепты в тестовом мире.
5. Записать фактические результаты, размер JAR и обнаруженные ограничения.

## Получение и использование

Руда генерируется в новых чанках биомов `end_highlands` и `end_midlands`.
Размещение заменяет верхний блок end_stone, до четырёх попыток на чанк.
В выживании разрушить руду незеритовой киркой: обработчик выдаёт один осколок.
Неподходящий инструмент, творческий режим и выключенный doTileDrops осколок не дают.
Из девяти осколков в сетке 3×3 получается один слиток.

Рабочий кузнечный рецепт: стандартный шаблон незеритового улучшения + соответствующий
незеритовый инструмент + один слиток Энда. На три инструмента — три слитка.
**Стоимость шаблона пока не согласована с командой; перед выпуском принять решение.**

Команды для тестового мира с разрешёнными читами:

```text
/give @s endsteel:end_ore 16
/give @s endsteel:end_shard 64
/give @s endsteel:end_ingot 3
/give @s endsteel:end_sword
/give @s endsteel:end_axe
/give @s endsteel:end_pickaxe
```

## Характеристики

| Параметр | Меч | Топор | Кирка |
|---|---:|---:|---:|
| Прочность | 2539 | 2539 | 2539 |
| Полный базовый урон | 12 | 15 | 6 |
| Скорость атаки | 1,6 | 1,0 | 1,2 |
| Эффективность добычи подходящих блоков | обычная для меча | 18 | 18 |
| Огнестойкость | да | да | да |

Прочность = round(2031 × 1,25); урон меча и топора = незеритовый × 1,5.
Ускорение добычи ×2 относится к параметру эффективности (9 → 18), а не ко всем
блокам и не обязательно к измеренному времени с учётом округления по тактам.
Бездна и кактус уничтожают инструменты. Зачарования и эффекты сравниваются отдельно.

## Обработка разрушения

`OreBreakHandler` запоминает допустимость в BEFORE, создаёт осколок в AFTER,
очищает запись в CANCELED и при отключении игрока. Проверяется совпадение позиции
и измерения. Это сохраняет корректность на последнем использовании кирки.
Таблица добычи руды пуста, чтобы не было второй награды. Серверные события
не дублируются клиентским обработчиком.

## Проверка механики

1. Включить выживание и doTileDrops, добыть две руды незеритовой киркой — по одному осколку.
2. Повторить алмазной киркой, рукой и в творческом режиме — без осколков.
3. Проверить кирку с последней единицей прочности — один осколок после поломки.
4. Проверить обычный блок, отменённое разрушение и выключенный doTileDrops — без эффекта Endsteel.
5. Проверить рецепты, названия, текстуры, урон, добычу, лаву, кактус, бездну и повторный вход.

## Ограничения и вклад

Fortune и Silk Touch не меняют фиксированную выдачу. Взрыв не выдаёт осколок.
По исходному требованию добыча разрешена именно незеритовой киркой, не киркой Endsteel.
Проверка нагрузки, визуального результата и работы установленного JAR ещё требуется.
Роли: Корсун Е.А. — код, конфигурация, сборка и документация;
Гордеев М.С. — визуальные ресурсы и игровые проверки.
